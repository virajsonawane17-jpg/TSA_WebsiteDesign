## Project Summary
A modern, centralized digital hub for Tampa, Florida residents to discover local community resources, nonprofit organizations, and support services. The "Tampa Community Resource Hub" serves as a civic-tech platform for finding food assistance, housing, mental health support, and more, specifically tailored to the Hillsborough County area.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Interactivity/Motion**: Framer Motion
- **Icons**: Lucide React
- **UI Components**: Shadcn UI (Radix UI)
- **State Management**: React Hooks (Search/Filter logic)

## Architecture
- `src/app`: Application routes and pages.
- `src/components`: Reusable UI and layout components.
- `src/lib`: Data constants, types, and utility functions.
- `src/hooks`: Custom hooks for search/filtering.

## User Preferences
- **Aesthetic**: Civic-tech, non-generic, human-designed.
- **Tone**: Welcoming, trustworthy, community-driven.
- **Accessibility**: High contrast, mobile-first, clear typography.
- **Constraint**: No login/accounts required.

## Project Guidelines
- Use real Tampa-based resource information.
- Minimize 'use client' by separating interactive logic.
- Ensure smooth scrolling and subtle transitions.
- No clichéd AI gradients or stock layouts.

## Common Patterns
- Search and dynamic filtering of lists.
- Card-based layouts for resource display.
- Forms with clear feedback/confirmation.
